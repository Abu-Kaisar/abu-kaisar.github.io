## 🚀 Local Development & Preview

To preview the portfolio locally, clone the repository and serve it using any local static web server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js npx serve
npx serve .
```

Then visit `http://localhost:8000` in your web browser.
